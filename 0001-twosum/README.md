  # Two Sum
  ## Исходные данные и условия
  Сложность: easy
  
https://leetcode.com/problems/two-sum/description/
  ## Решение
Первый цикл `for (int i = 0; i < nums.size(); i++)` для перебора всех индексов массива с 0 до `nums.size()` - последнего индекса массива

Второй цикл `for (int j = i + 1; j < nums.size(); j++)` для перебора всех индексов i+1

После идет условие `if (nums[i] + nums[j] == target)`, чтобы найти подходящие индексы, если сумма значения под индексом i и индексом j будет равна target, то

  `return {i, j};` - функция возвращает vector с 2 индексами
  
Хоть по условия задачи и сказано, что есть хотя бы одно решение, для исключения ошибки добавлено `return {};` что ничего не возвращает в случае, если решения нет.
