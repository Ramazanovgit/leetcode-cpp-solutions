 # Maximum Subarray
  ## Исходные данные и условия
  Сложность: Medium
  
https://leetcode.com/problems/maximum-subarray/description/
  ## Решение
 ``` 
 int sum = nums[0];
int maxSum = nums[0];
```
Вводим `sum` = Первому элементу массива, переменная будет считать, оставлять счет с данного числа, или начинать новый массив, `maxSum` будет принимать максимальную `sum` из всех вариантов массивов.
```
 for (int i = 1; i < nums.size(); i++) {
            sum = max(sum + nums[i], nums[i]);
            maxSum = max(sum, maxSum);
        }
```
Начинаем цикл с 1 элемента массива, т.к 0 уже задан

За `sum` берем большее число, либо `sum` либо `sum` + последующий элемент массива

Пример: -2; 1; -3. `sum = -2`,  после чего сравнивается с `-2 + 1 = -1`, т.е счет лучше начинать с 1, а не с -2 и т.д.

`maxSum` запоминает наибольший `sum` в случае зануления

Пример: 99; -100; 50. Цикл будет идти: `sum = 99`, потом, т.к 99+(-100) = -1 начнет новый массив с 50, при этом `maxSum` запомнит максимальную `sum = 99`, а не 50

`return maxSum;` возвращает максимальную сумму.
