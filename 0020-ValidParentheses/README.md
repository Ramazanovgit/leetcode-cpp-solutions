  # Valid Parentheses
  ## Исходные данные и условия
  Сложность: easy
  
https://leetcode.com/problems/valid-parentheses/description/
  ## Решение
`stack<char> st;` - Создаем стек, будем складывать туда открытые скобки - `(` `[` и `{`.

 `for (int i = 0; i < s.size(); i++)` - начинаем цикл, в котором `i` будет индексом для `s`.

 ```
 if (s[i] == '(' || s[i] == '[' || s[i] == '{') {
                st.push(s[i]);
            }
```
Создаем условие проверки символа, если подходящий (открытая скобка) кладем в стек.

```
else {
                if (st.empty()) {
                    return false;
                }
```
Иначе, если стек пустой возвращаем `false` в `isValid`, т.к если не пройдет по первому условию открытой скобки и стек пустой, то в него первой войдет закрытая скобка, чего быть не может для решения.

```
if (s[i] == ')' && st.top() == '(') {
                    st.pop();
                }
                else if (s[i] == ']' && st.top() == '[') {
                    st.pop();
                }
                else if (s[i] == '}' && st.top() == '{') {
                    st.pop();
                }
                else {
                    return false;
```
                
Дальше идет проверка, если попалась закрытая скобка любого варианта **И** `st.top()` является открытой скобкой того же варианта то она удаляется из `stack`. Иначе `false` в `isValid`.

После завершения цикла проверяем, пуст ли стек. Если пуст — все открывающие скобки были закрыты корректно, поэтому функция возвращает `true`. Если стек не пуст — остались незакрытые скобки, поэтому возвращается `false`.
