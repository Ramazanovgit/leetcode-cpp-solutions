# Number of Islands
  ## Исходные данные и условия
  Сложность: Medium/hard
  
https://leetcode.com/problems/number-of-islands/description/
  ## Решение
`int count = 0;` - Вводим `count` — переменную, которая будет считать количество островов.
```
for (int i = 0; i < grid.size(); i++) {
            for (int j = 0; j < grid[i].size(); j++) {

                if (grid[i][j] == '1') {
                    count++;
                    dfs(grid, i, j);
                }
            }
        }
```
Проходим по всей таблице, где i - строка, j - столбец, если находим 1 - остров. Увеличиваем `count` на единицу и вызываем функцию `dfs`, которая помечает весь остров.

```
void dfs(vector<vector<char>>& grid, int i, int j) {
        if (i < 0 || i >= grid.size() ||
            j < 0 || j >= grid[i].size() ||
            grid[i][j] != '1') {
            return;
        }
        grid[i][j] = '2';
        dfs(grid, i - 1, j);
        dfs(grid, i + 1, j);
        dfs(grid, i, j - 1);
        dfs(grid, i, j + 1);
    }
```
`dfs` Получает координаты i и j и проверяет чтобы при заполнении(превращении в 2) острова, не вышли за грани, т.е сделал условия `return` в случае если не 1 в клетке.

После проверки превращаем клетку в 2 и вызываем функцию с другими координатами, для проверки соседних клеток, не считая диагональных, по условию.

`return count;` - Возвращаем количество островов.
